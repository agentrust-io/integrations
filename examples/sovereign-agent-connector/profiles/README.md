# Profiles

No profile is normative or frozen. The French-healthcare scenario in
`vectors/french-healthcare/` is an experimental deployment profile used to
validate the core bindings.

Profile identifiers used by the code and vectors:

- `https://agentrust-io.com/profiles/aucp/v0.1`: the base composition bundle and
  its usage-control receipts.
- `https://agentrust-io.com/profiles/aucp/v0.1/cmcp-mve1`: the live cMCP adapter
  bundle that wraps the base bundle.
