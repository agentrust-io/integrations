# Decision 0001: AUCP is a composition profile, not a new stack

**Status:** Accepted (experimental)  
**Date:** 2026-08-13

AUCP defines only agreement projection, authority binding, usage-obligation
attenuation, action-level joins, dispatch-state semantics, evidence completeness,
and cross-artifact conformance.

It reuses Dataspace Protocol/ODRL, AAT or mapped cA2A authority, RATS/EAT,
OAuth/MCP, TRACE, and SCITT. "Sovereign Agent Connector" is the first deployment
profile and demonstration, not the foundational protocol name.

The detailed evidence is in `docs/standards-gap.md`.


**Amended 2026-10-08:** the experiment moved from a private repository into
`agentrust-io/integrations` as the `sovereign-agent-connector` example.
